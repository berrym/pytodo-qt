First prerelease of the v0.3.11 series. Ship-verified binaries for macOS, Linux, and Windows are attached to this release with SHA-256 checksums. This is a beta — bugs are expected. Please [open an issue](https://github.com/berrym/pytodo-qt/issues/new) if you hit anything.

## Installers (new in v0.3.11)

The v0.3.10 release shipped hand-rolled archives; v0.3.11 ships native-per-platform installers:

- **macOS**: `.dmg` with drag-to-Applications layout and first-launch instructions baked into the DMG background. Ad-hoc signed — on first launch, right-click → Open, enter password, check "Always allow".
- **Linux**: `.AppImage` (self-contained, single file) and `.tar.gz` (traditional `install.sh` flow), both x86_64 and arm64. See the README's "Making the AppImage file show the PyTodo-Qt icon in your file manager" section for the three DE-specific paths.
- **Windows**: Inno Setup `.exe` installer (per-user install, no admin required) and `.zip`, x86_64.

Every artifact ships with a sibling `.sha256` file in `sha256sum -c` / `shasum -a 256 -c` compatible format.

## New features

### Calendar
- Drag-and-drop visuals: drop-target cell highlight and a floating date/time preview label that follows the cursor in day/week views.
- Double-click any task to open the Edit Reminder dialog (wire-up of a long-standing TODO).
- Multi-hour bars label exactly once, no more duplicate labels on cross-hour tasks.
- Cross-midnight tasks now render correctly on both days in week and day views (previously invisible on the day they spanned into).
- All Day row sized consistently between day and week views; Linux header clipping fixed.

### Smart-add quick actions
Row of four trigger buttons under the smart-input text field — **Priority**, **Date**, **Tag**, **Recurrence** — each opening a preset menu. Clicking a preset inserts the corresponding NLP token into the input (rather than setting parse state directly), so the text field always reflects exactly what the parser would have parsed from typing. Keeps the NLP-first design intact while giving click-driven users a discoverable entry point.

### Kanban
- Three-case empty state overlay: "No tasks yet" (zero-item list) / "All done!" (all tasks complete + incomplete filter) / "No tasks match the current filter" (generic filter-induced empty). Each case has an escape-hatch button back to your data.
- Column dropdown when adding a new task. Clicking "+" in a specific column pre-selects it; choosing Add Todo from the menu defaults to the first column.

### NLP / Voice dictation
- "first Monday of next month", "last Friday of April", "second Tuesday of May" and related Nth-weekday-of-month patterns.
- Extended fractional-hour durations: "an hour and a half", "three quarters of an hour", "a quarter of an hour", "one hour thirty" (no "and" required), "half an hour".
- "in <fractional hour>" correctly resolved as relative future time (e.g. "lunch in half an hour" schedules for 30 min from now, not a 30-minute duration).
- Filler-word handling, half-past / quarter-to time phrases, time-block words — all verified across the 112-entry voice corpus (tests/test_nlp_voice_corpus.py).

### Settings dialog
- Default View dropdown now includes Calendar alongside List and Board.
- New "Remember last view between sessions" checkbox — when unchecked, the dropdown actually acts as your default view (previously the dropdown was vestigial because runtime view switches always overwrote it). Default on preserves previous behaviour.
- All input widgets have consistent vertical sizing — fixes Focus Timer spin-box text clipping reported on Linux and Windows.
- Service name, fingerprint, and pairing PIN widgets widened to fit their full contents.

### Mobile Access
- Rename button on each paired device in the Mobile Access Wizard. API endpoint existed since the per-device auth work landed; the UI catches up.

### Infrastructure / quality
- matplotlib is now a core dependency and bundled in the binaries. Chart export (PNG + PDF) works out of the box across all shipping formats — no separate install step.
- Bundled Noto Sans fonts so the "extra wide" text rendering issue in v0.3.10-era binaries (where the fallback font had different metrics than the parser expected) is gone.
- Several latent Qt font-alias warnings eliminated (`SF Mono`, generic `monospace` literals).
- PyPI prerelease guard: beta/rc/dev tags never reach PyPI automatically.

## Noteworthy fixes

- Multi-hour calendar bars rendered their label once per hour cell they spanned; now renders once per bar.
- Cross-midnight recurring tasks were invisible on the adjacent day in week view.
- 25-minute tasks crossing an hour boundary appeared as two separate tasks.
- Release binaries had "extra wide" letter spacing because Qt fell back to a mismatched font family.
- "Add To-Do" / "to-do" inconsistency with the PyTodo-Qt brand renamed to "Add Todo" / "todo" across six user-visible strings.

## Beta caveats

- This is `0.3.11b1`, not `0.3.11`. The `b1` designator (PEP 440 beta) means bugs are expected; if you find any, please report them so `0.3.11b2` or the eventual `0.3.11` final can ship clean.
- macOS builds are ad-hoc signed (not notarized with an Apple Developer ID). Right-click → Open on first launch.
- Linux AppImage file-manager icon requires `xapp-thumbnailers` (GTK DEs) or `kio-extras`+`libappimage` (KDE) or AppImageLauncher — see README for details.
- Windows installer is per-user and not code-signed.
